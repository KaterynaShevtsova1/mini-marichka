# Міні-Марічка

AI-помічниця в Telegram для учениць курсу «Система з AI» (Катерина Шевцова). Живе на власному сервері учениці, працює на її Claude Pro, читає її «Контекст» з Notion. У команді: ✍️ Лея (тексти), 🎬 Марко (каруселі), 💡 Мія (дослідження, за бажанням).

Тут немає нічиїх особистих даних: це шаблон. Сервер учениці щоночі забирає звідси оновлення, а її пам'ять і файли лишаються в неї.

Ставиться не руками: у курсі є пакет «розгорни» для Claude Desktop, він створює сервер і запускає `install.sh`.

| Що | Де |
|---|---|
| бот (Telegram + Claude Code) | `bot/` |
| правила роботи | `workspace/CLAUDE.md` |
| перші файли пам'яті (заповнюються при знайомстві) | `bot/dna/` |
| помічники | `agents/` |
| навички | `skills/` |
| скрипти: «Контекст» з Notion, PNG каруселей, оновлення | `bin/` |
| каркас каруселі | `shablony/` |
| встановлення на чистий Ubuntu 24.04 | `install.sh` |
